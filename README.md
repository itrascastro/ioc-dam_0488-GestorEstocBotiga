# GestorEstocBotiga

Projecte d'exemple de la **Unitat 1** del mòdul DAM_0488 - Desenvolupament d'interfícies (IOC). Tots els codis i captures d'aquesta unitat dels materials provenen d'aquest projecte.

Gestió d'estoc d'una botiga: formulari principal dissenyat amb l'editor visual de Windows Forms, component visual propi `IndicadorEstoc`, persistència en fitxer, proves unitàries i documentació de codi.

Materials de la unitat: https://itrascastro.github.io/ioc/dam_0488/unitat-1/

## Requisits

- Windows 10/11.
- Visual Studio Community 2022 o superior amb la càrrega de treball **.NET desktop development**.
- .NET SDK 8 (`net8.0-windows`).

## Com obrir-lo

1. Cloneu el repositori o descarregueu-lo com a ZIP (Code → Download ZIP).
2. Obriu `GestorEstocBotiga.slnx` amb Visual Studio.
3. Establiu `GestorEstocBotiga` com a projecte d'inici i executeu-lo (F5). Els paquets NuGet es restauren automàticament.
4. Les proves s'executen des de l'Explorador de proves (Test → Test Explorer) o amb `dotnet test`.

## Contingut
- `GestorEstocBotiga/`: aplicació Windows Forms.
- `GestorEstocBotiga.Tests/`: proves unitàries (xUnit).

No és el mateix exercici que es demana a les activitats avaluables: és un exemple complet que treballa les mateixes tècniques.
